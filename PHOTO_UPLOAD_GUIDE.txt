UPLOAD PHOTO IMPLEMENTATION
================================================================================

```javascript
import * as ImagePicker from 'expo-image-picker';

const uploadPhoto = async (token) => {
  // Pick image from library
  const result = await ImagePicker.launchImageLibraryAsync({
    mediaTypes: ImagePicker.MediaTypeOptions.Images,
    allowsEditing: true,
    aspect: [1, 1],
    quality: 0.8,
  });

  if (result.canceled) return;

  const uri = result.assets[0].uri;
  const fileName = uri.split('/').pop();

  // Create FormData
  const formData = new FormData();
  formData.append('photo', {
    uri: uri,
    type: 'image/jpeg',
    name: fileName,
  });

  // Upload
  try {
    const response = await fetch(`${API_URL}/api/me/photo`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
      },
      body: formData,
    });

    const data = await response.json();

    if (response.ok) {
      console.log('Photo uploaded:', data.data.photo_url);
      // Refresh user profile to get new photo URL
      await getUserProfile(token);
    } else {
      console.error('Upload failed:', data);
      Alert.alert('Error', 'Failed to upload photo');
    }
  } catch (error) {
    console.error('Upload error:', error);
    Alert.alert('Error', error.message);
  }
};
```

COMMON ISSUES
================================================================================

Issue: "Cannot find module ImagePicker"
Solution: npm install expo-image-picker

Issue: "Image won't display"
Solution: Check if URL is correct format (/storage/photos/xxx.jpg)

Issue: "Upload fails with 422 Unprocessable Entity"
Solution:
  - File must be image/jpeg or image/png
  - File size must be < 5MB
  - Field name must be "photo"

Issue: "File appears corrupted (white image)"
Solution:
  - Check FormData field format
  - Verify file is selected before upload
  - Check file permissions on server

Issue: "URL works in browser but not in app"
Solution:
  - Might need full URL instead of relative
  - Try: `${API_URL}/storage/photos/xxx.jpg`
  - Check CORS headers if cross-domain
