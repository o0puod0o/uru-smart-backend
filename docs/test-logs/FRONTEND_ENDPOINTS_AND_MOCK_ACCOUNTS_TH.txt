============================================================
BASE URL
============================================================

Local เครื่องตัวเอง:
http://localhost:8001/api

LAN สำหรับเครื่องอื่นในวงเดียวกัน:
http://10.1.73.75:8001/api

phpMyAdmin:
http://10.1.73.75:8081

หมายเหตุ:
- ทุก endpoint ที่อยู่หลัง login ต้องส่ง Header:
  Authorization: Bearer <token>
  Accept: application/json
- Frontend ใช้ endpoint login เดิมได้เลย ไม่ต้องเรียก mock-sso เอง
- mock-sso เป็นตัวจำลอง SSO จริงภายใน backend
- ตอนใช้ mock ชั่วคราวบน server สามารถเปิด SSO_FAST_MOCK=true เพื่อไม่ให้ backend ยิง HTTP วนหา mock-sso เอง ทำให้ login เร็วขึ้น

5) FLOW สำหรับ FRONTEND
============================================================

Step 1: Login
POST http://10.1.73.75:8001/api/auth/login
Body:
{
  "email": "mockuser01@gmail.com",
  "password": "password"
}

Step 2: เก็บ token จาก response
token = response.token

Step 3: เรียก endpoint อื่นโดยแนบ header
Authorization: Bearer <token>
Accept: application/json

ตัวอย่าง:
GET http://10.1.73.75:8001/api/me
GET http://10.1.73.75:8001/api/lrd/researchs
POST http://10.1.73.75:8001/api/lrd/researchs

Step 4: Logout
POST http://10.1.73.75:8001/api/auth/logout
