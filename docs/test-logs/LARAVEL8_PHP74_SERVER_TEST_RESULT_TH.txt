หมายเหตุ:
- ตัวนี้เป็น Laravel 8 test app สำหรับพิสูจน์ปัญหา PHP version เท่านั้น
- Laravel 10 ตัวหลักยังติด PHP version บน server เพราะ server ใช้ PHP 7.4.9 แต่ Laravel 10 ต้องใช้ PHP 8.1/8.2 ขึ้นไปตาม dependency
- ถ้า server เปลี่ยน PHP ไม่ได้ ทางเลือกที่ใช้งานได้คือปรับ backend production เป็น Laravel 8-compatible หรือใช้ temporary PHP 7.4 mock/shim ระหว่างรอ server จริง
