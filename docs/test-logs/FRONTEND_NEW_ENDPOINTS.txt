URU SMART - FRONTEND ENDPOINTS ADDED/UPDATED
===========================================

Base API URL
------------

https://aritapp.uru.ac.th/urusmart/api


Required Header for Protected APIs
----------------------------------

Authorization: Bearer <token>
Accept: application/json


Important Server Note: PUT / PATCH / DELETE
-------------------------------------------

On this IIS server, direct PUT / PATCH / DELETE may fail.
Use POST with X-HTTP-Method-Override instead.

Example DELETE:

POST https://aritapp.uru.ac.th/urusmart/api/proposals/1
X-HTTP-Method-Override: DELETE
Authorization: Bearer <token>
Accept: application/json

Body can be empty or:

{
  "_method": "DELETE"
}

7) Frontend Axios Method Override Example
-----------------------------------------

Use this if the server has issues with PUT / PATCH / DELETE.

api.interceptors.request.use((config) => {
  const method = config.method?.toLowerCase();

  if (['put', 'patch', 'delete'].includes(method)) {
    config.headers['X-HTTP-Method-Override'] = method.toUpperCase();
    config.method = 'post';
    config.data ??= {};
  }

  return config;
});


8) Insert Success But List Not Showing Checklist
------------------------------------------------

If POST/insert succeeds but the new item does not show in frontend:

1. Check if frontend refetches the list after POST.
2. Check cache invalidation if using React Query / SWR / custom cache.
3. Check GET query params:
   - scope=mine or scope=all
   - status
   - year
   - q
   - page
4. Check response shape:
   - list may be in response.data.data
   - pagination meta may be in response.data.meta
5. Check whether created item has status that is hidden by current filter.
