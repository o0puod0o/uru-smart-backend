Final explanation for teacher:

Laravel หนึ่งโปรเจกต์สามารถเชื่อมต่อฐานข้อมูลได้มากกว่าหนึ่ง database โดยใช้ connection หลายตัวใน config/database.php ในโปรเจกต์นี้ตั้ง connection หลักชื่อ mysql ไปที่ database mobile_db และ connection ที่สองชื่อ mysql_second ไปที่ database mobile_second_db ทั้งสอง database อยู่บน MySQL server เดียวกันและใช้ port เดียวกันคือ db:3306 ภายใน Docker แต่ Laravel เลือก database ต่างกันผ่านค่า database ของแต่ละ connection

หน้า /db-connections-demo แสดงให้เห็นแบบเป็นรูปธรรม โดยฝั่งซ้ายดึงข้อมูลจาก mobile_db.users และฝั่งขวาดึงข้อมูลจาก mobile_second_db.external_training_courses มาแสดงใน Blade view เดียวกัน ผลทดสอบหน้าเว็บตอบ HTTP 200 และพบข้อมูลจากทั้งสอง database จริง จึงยืนยันได้ว่าสามารถใช้ multiple database connection ใน Laravel ได้จริงทั้งใน command line และหน้าเว็บ
