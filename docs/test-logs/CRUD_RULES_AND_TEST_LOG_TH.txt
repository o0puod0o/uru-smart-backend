1) กติกาการใช้งาน Database
---------------------------

- SSO user

- lrdsystem2.users
- lrdsystem2.researchers

- expert2.education

- expert2.has_journal

2) Endpoint ที่ปรับให้ใช้ expert2
---------------------------------

GET/POST/PUT/DELETE /api/educations
-> expert2.education

GET/POST/PUT/DELETE /api/interests
-> expert2.has_interest

GET/POST/PUT/DELETE /api/researches
-> expert2.has_research

GET/POST/PUT/DELETE /api/journals
-> expert2.has_journal

GET/POST/PUT/DELETE /api/workexes
-> expert2.workex

หมายเหตุ:
backend ใช้ citizen_id ของ user ที่ login เป็น id_card ให้อัตโนมัติ
frontend ไม่ต้องส่ง id_card มาเอง


3) Endpoint ที่เพิ่มสำหรับ lrdsystem2
-------------------------------------

GET/POST/PUT/DELETE /api/lrd/projects
-> lrdsystem2.projects

GET/POST/PUT/DELETE /api/lrd/researchs
-> lrdsystem2.researchs

GET/POST/PUT/DELETE /api/lrd/proposals
-> lrdsystem2.proposals

หมายเหตุ:
backend ใช้ researcher_id จาก mapping ของ user ที่ login ให้อัตโนมัติ
frontend ไม่ต้องส่ง researcher_id มาเอง

11) สรุปผลรวม
-------------

PASS:

- user/master tables ยังคงเป็น read-only
- expert2.users ไม่ถูก update
- lrdsystem2.users ไม่ถูก update
- lrdsystem2.researchers ไม่ถูก update
- expert2 education/research/journal/interest/workex รองรับ CRUD ผ่าน API แล้ว
- lrdsystem2 projects/researchs/proposals รองรับ CRUD ผ่าน API แล้ว
- backend ใช้ token ของ user login เพื่อหา id_card/researcher_id เอง
- frontend ไม่ต้องส่ง id_card หรือ researcher_id มาเอง

สรุปสุดท้าย:

ระบบรองรับแนวทางตามอาจารย์แล้ว:

ตาราง user/master อ่านอย่างเดียว
ตารางข้อมูลประกอบ expert/research สามารถอ่าน สร้าง แก้ไข และลบได้ผ่าน Laravel API
