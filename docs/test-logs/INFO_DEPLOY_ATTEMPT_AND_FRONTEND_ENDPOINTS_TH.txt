3) SSO จริง
============================================================

ค่าจากอาจารย์:

clientSecret = state
redirectUri = https://urusmart.uru.ac.th/auth/callback

Callback endpoint ที่เตรียมไว้:

รองรับ query:

1. ตรวจ token/code กับ SSO

4. ออก Sanctum token ให้ mobile app

6) Axios method override สำหรับ frontend
============================================================

ถ้า IIS ยังทำให้ PUT/PATCH/DELETE ไป PHP 7.4 ให้ใช้ interceptor นี้:

api.interceptors.request.use((config) => {
  const method = config.method?.toLowerCase();

  if (['put', 'patch', 'delete'].includes(method)) {
    config.headers['X-HTTP-Method-Override'] = method.toUpperCase();
    config.method = 'post';
    config.data ??= {};
  }

  return config;
});

7) Database ที่ระบบต้องใช้
============================================================

ระบบใช้ 3 logical connections:

1. mobile/main database
   ใช้เก็บ user กลาง, token, notification, mobile-owned data

2. expert database
   ใช้ดึง/จัดการข้อมูล expert profile
   ตาราง users ใน expert เป็น read-only

3. lrd database
   ใช้ module งานวิจัย
   ตาราง users และ researchers เป็น read-only

ต้องยืนยันว่าบน server มี database เหล่านี้:
- urusmart
- expert2
- lrdsystem2

หรือถ้าใช้ credential เดียว ต้องให้ user นั้นมีสิทธิ์เข้าทั้ง 3 database
