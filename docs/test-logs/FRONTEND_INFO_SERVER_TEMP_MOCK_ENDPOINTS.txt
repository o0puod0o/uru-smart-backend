============================================================
AUTH
============================================================

Login
POST https://info.uru.ac.th/server/api/auth/login

Body JSON:
{
  "email": "mockuser01@gmail.com",
  "password": "password"
}

หรือ form-data/x-www-form-urlencoded:
email=mockuser01@gmail.com
password=password

Response:
{
  "token": "php74-mock...",
  "user": {
    "id": 7,
    "code": "2180",
    "full_name_th": "Mock User01",
    "full_name_en": "Mock User01",
    "email": "mockuser01@gmail.com",
    "faculty_name_th": "Uttaradit Rajabhat University",
    "department_name_th": "Demo Department",
    "picture": null
  }
}

หลัง login ให้ส่ง header:
Authorization: Bearer <token>
Accept: application/json

Logout
POST https://info.uru.ac.th/server/api/auth/logout
