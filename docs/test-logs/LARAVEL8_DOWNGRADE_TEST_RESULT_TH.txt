3. แก้ config/app.php จาก Laravel 10 style เป็น Laravel 8 style
4. แก้ config/logging.php ให้เข้ากับ Monolog 2

   - match expression
   - nullsafe operator (?->)
   - constructor property promotion
6. แก้ middleware signature ให้เข้ากับ Laravel 8
7. แก้ test helper ที่มีเฉพาะ Laravel 10 เช่น fake() และ assertJsonIsArray()
8. เพิ่ม fruitcake/laravel-cors สำหรับ CORS middleware ของ Laravel 8
9. เอา temporary PHP mock route และ Laravel 8 mini-test route ออกจาก public/web.config แล้ว
