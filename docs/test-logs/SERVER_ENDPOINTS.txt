IMPORTANT: IIS METHOD OVERRIDE
------------------------------

Server ปัจจุบันส่ง GET/POST ไป PHP 8.2 แต่ส่ง PUT/PATCH/DELETE ไป PHP 7.4
Frontend จึงต้องเปลี่ยน PUT/PATCH/DELETE เป็น POST พร้อม header:

X-HTTP-Method-Override: PUT
X-HTTP-Method-Override: PATCH
X-HTTP-Method-Override: DELETE

Axios interceptor:

api.interceptors.request.use((config) => {
  const method = config.method?.toLowerCase();

  if (['put', 'patch', 'delete'].includes(method)) {
    config.headers['X-HTTP-Method-Override'] = method.toUpperCase();
    config.method = 'post';
    config.data ??= {};
  }

  return config;
});

เมื่อใส่ interceptor แล้ว frontend ยังเรียกแบบเดิมได้:

api.put('/awards/2', data);
api.delete('/awards/2');
