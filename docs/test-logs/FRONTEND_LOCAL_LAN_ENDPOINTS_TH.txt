URU Smart Backend - Local LAN API Endpoints สำหรับ Frontend
วันที่ทำไฟล์: 2026-08-17

Base URL สำหรับเครื่องในวง LAN เดียวกัน:

http://10.1.73.75:8001

API Base URL:

http://10.1.73.75:8001/api

หมายเหตุ:
- เครื่อง backend ต้องเปิด Docker อยู่
- มือถือ/เครื่อง frontend ต้องอยู่ Wi-Fi/LAN วงเดียวกัน
- ทุก endpoint หลัง login ต้องส่ง header:

Authorization: Bearer <token>
Accept: application/json

============================================================
1) AUTH / APP หลัก
============================================================

ใช้สำหรับ login/logout และข้อมูล user ที่ login อยู่

POST   http://10.1.73.75:8001/api/auth/login
POST   http://10.1.73.75:8001/api/auth/logout
GET    http://10.1.73.75:8001/api/me
PUT    http://10.1.73.75:8001/api/me
GET    http://10.1.73.75:8001/api/me/external-profile
POST   http://10.1.73.75:8001/api/me/photo
DELETE http://10.1.73.75:8001/api/me/photo

ตัวอย่าง login:

POST /api/auth/login

Body:
email=3530900177802
password=password

Response จะได้ token:

{
  "token": "<token>",
  "user": {
    "id": 1,
    "code": "...",
    "full_name_th": "...",
    "email": "..."
  }
}

หลังจากนั้นให้ frontend เอา token ไปใส่ header ทุกครั้ง

Authorization: Bearer <token>

หมายเหตุ:
- ช่อง email ใน login ใช้เป็น identifier ได้ เช่น email / username / id_card ตาม SSO
- PUT /api/me แก้ได้เฉพาะข้อมูลของ mobile app เช่น เบอร์, bio, line, address
- ข้อมูล master เช่น ชื่อ, นามสกุล, prefix, วันเกิด, หน่วยงาน มาจาก SSO/user master ไม่ให้ mobile override

3) MODULE งานวิจัย - อิง lrdsystem2

============================================================
4) สรุป flow สำหรับ frontend
============================================================

1. Login:
POST http://10.1.73.75:8001/api/auth/login

2. เก็บ token จาก response

3. เรียกข้อมูล user:
GET http://10.1.73.75:8001/api/me

4. ถ้าจะใช้ข้อมูล app/expert profile:
ใช้ endpoint กลุ่ม /api/educations, /api/researches, /api/journals, ...

5. ถ้าจะเข้า module งานวิจัย:
ใช้ endpoint กลุ่ม /api/lrd/...

6. ทุก request หลัง login ต้องแนบ:
Authorization: Bearer <token>

============================================================
5) สรุปแยก database
============================================================

mobile_db:
- users ที่ login เข้า app
- token
- notification
- ข้อมูล app เฉพาะทางที่ไม่ได้อยู่ใน expert2/lrdsystem2

expert2:
- users = read-only
- education / has_interest / has_research / has_journal / workex = CRUD
- ผูกเจ้าของด้วย id_card

lrdsystem2:
- users = read-only
- researchers = read-only
- papers / projects / researchs / proposals / educations = CRUD
- ผูกเจ้าของด้วย researcher_id
