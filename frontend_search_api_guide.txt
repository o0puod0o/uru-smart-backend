Frontend Search API Guide
Mobile Backend

ทุก endpoint ด้านล่างต้องส่ง header:

Authorization: Bearer <token>
Accept: application/json

Base URL ตัวอย่าง:
http://localhost:8001

============================================================
ส่วนที่ 1: Dropdown "ค้นหาจาก"
============================================================

ใช้กับ dropdown ในรูปที่มีตัวเลือก:
- ชื่อ
- นามสกุล
- กลุ่มความเชี่ยวชาญ
- ความสนใจ
- ผลงานวิจัย
- Proceeding
- Journal

Endpoint:

GET /api/ref/search-fields

ตัวอย่าง Request:

GET http://localhost:8001/api/ref/search-fields

Response:

[
  { "id": "first_name", "name": "ชื่อ" },
  { "id": "last_name", "name": "นามสกุล" },
  { "id": "expertise_group", "name": "กลุ่มความเชี่ยวชาญ" },
  { "id": "interest", "name": "ความสนใจ" },
  { "id": "research", "name": "ผลงานวิจัย" },
  { "id": "proceeding", "name": "Proceeding" },
  { "id": "journal", "name": "Journal" }
]

Frontend ใช้งาน:
- ใช้ name แสดงใน dropdown
- ใช้ id เป็น value ที่ส่งกลับ backend

ตัวอย่าง map สำหรับ dropdown:

const searchFieldItems = data.map(item => ({
  label: item.name,
  value: item.id,
}));

------------------------------------------------------------
ค้นหาจาก dropdown "ค้นหาจาก" + ช่องกรอกคำค้น
------------------------------------------------------------

Endpoint:

GET /api/profile-search?search_from=<field_id>&keyword=<keyword>

Query params:

search_from:
  optional แต่ควรส่งเมื่อ user เลือก dropdown
  ค่าที่ใช้ได้:
  - first_name
  - last_name
  - expertise_group
  - interest
  - research
  - proceeding
  - journal

keyword:
  optional
  คำที่ user พิมพ์ในช่องค้นหา

limit:
  optional
  default = 20
  max = 100

ตัวอย่าง:

GET /api/profile-search?search_from=first_name&keyword=สมชาย

GET /api/profile-search?search_from=interest&keyword=Machine%20Learning

GET /api/profile-search?search_from=journal&keyword=AI

Response:

[
  {
    "id": 1,
    "full_name_th": "ดร. สมชาย ใจดี",
    "full_name_en": "Dr. Somchai Jaidee",
    "email": "somchai@example.com",
    "picture": "https://...",
    "position": "อาจารย์",
    "department_name_th": "คณะวิทยาศาสตร์และเทคโนโลยี",
    "department_name_en": "Faculty of Science and Technology"
  }
]

Frontend flow:

1. เปิดหน้า search
2. เรียก GET /api/ref/search-fields
3. เอา response ไปทำ dropdown "ค้นหาจาก"
4. user เลือก field เช่น interest
5. user พิมพ์คำค้น เช่น Machine Learning
6. กดค้นหา
7. เรียก GET /api/profile-search?search_from=interest&keyword=Machine%20Learning
8. เอา response ไป render รายชื่อ

ตัวอย่าง fetch:

const params = new URLSearchParams({
  search_from: selectedSearchField,
  keyword: keyword,
  limit: '20',
});

const res = await fetch(`${API_URL}/api/profile-search?${params.toString()}`, {
  headers: {
    Authorization: `Bearer ${token}`,
    Accept: 'application/json',
  },
});

const users = await res.json();

============================================================
ส่วนที่ 2: Dropdown กลุ่มความเชี่ยวชาญ + ความสนใจ 400+ รายการ
============================================================

ใช้กับ dropdown ในรูป:
- ค้นหาตามกลุ่มความเชี่ยวชาญ
- เลือกความสนใจ

ข้อมูลมาจากไฟล์:
database/data/unique_options.txt

Endpoint:

GET /api/ref/search-options

ตัวอย่าง Request:

GET http://localhost:8001/api/ref/search-options

Response:

{
  "search_from": [
    { "id": "first_name", "name": "ชื่อ" },
    { "id": "last_name", "name": "นามสกุล" },
    { "id": "expertise_group", "name": "กลุ่มความเชี่ยวชาญ" },
    { "id": "interest", "name": "ความสนใจ" },
    { "id": "research", "name": "ผลงานวิจัย" },
    { "id": "proceeding", "name": "Proceeding" },
    { "id": "journal", "name": "Journal" }
  ],
  "expertise_groups": [
    { "id": "all", "name": "กลุ่มความเชี่ยวชาญทั้งหมด" },
    { "id": "Artificial Intelligence (AI)", "name": "Artificial Intelligence (AI)" },
    { "id": "Machine Learning", "name": "Machine Learning" }
  ],
  "interests": [
    { "id": "all", "name": "ความสนใจทั้งหมด" },
    { "id": "Artificial Intelligence (AI)", "name": "Artificial Intelligence (AI)" },
    { "id": "Machine Learning", "name": "Machine Learning" }
  ]
}

หมายเหตุ:
- expertise_groups และ interests จะมีรายการจำนวนมาก ประมาณ 480 รายการ
- ช่องบน ใช้ expertise_groups
- ช่องล่าง ใช้ interests
- ใช้ name แสดงใน dropdown
- ใช้ id เป็น value ที่ส่งกลับ backend
- id = all หมายถึงเลือกทั้งหมด

ตัวอย่าง map สำหรับ frontend:

const expertiseItems = data.expertise_groups.map(item => ({
  label: item.name,
  value: item.id,
}));

const interestItems = data.interests.map(item => ({
  label: item.name,
  value: item.id,
}));

------------------------------------------------------------
ค้นหาจาก dropdown กลุ่มความเชี่ยวชาญ + ความสนใจ
------------------------------------------------------------

Endpoint:

GET /api/profile-search?expertise_group=<value>&interest=<value>

Query params:

expertise_group:
  optional
  ใช้ value จาก expertise_groups.id
  ถ้าเลือกทั้งหมดให้ส่ง all

interest:
  optional
  ใช้ value จาก interests.id
  ถ้าเลือกทั้งหมดให้ส่ง all

keyword:
  optional
  ใช้ค้นหาชื่อ/email เพิ่มเติมได้

limit:
  optional
  default = 20
  max = 100

ตัวอย่างเลือกทั้งหมด:

GET /api/profile-search?expertise_group=all&interest=all

ตัวอย่างเลือกกลุ่มความเชี่ยวชาญอย่างเดียว:

GET /api/profile-search?expertise_group=Artificial%20Intelligence%20(AI)&interest=all

ตัวอย่างเลือกความสนใจอย่างเดียว:

GET /api/profile-search?expertise_group=all&interest=Machine%20Learning

ตัวอย่างเลือกทั้งสองช่อง:

GET /api/profile-search?expertise_group=Artificial%20Intelligence%20(AI)&interest=Machine%20Learning

Response:

[
  {
    "id": 1,
    "full_name_th": "ดร. สมชาย ใจดี",
    "full_name_en": "Dr. Somchai Jaidee",
    "email": "somchai@example.com",
    "picture": "https://...",
    "position": "อาจารย์",
    "department_name_th": "คณะวิทยาศาสตร์และเทคโนโลยี",
    "department_name_en": "Faculty of Science and Technology"
  }
]

Frontend flow:

1. เปิดหน้า search
2. เรียก GET /api/ref/search-options
3. เอา expertise_groups ไปทำ dropdown "ค้นหาตามกลุ่มความเชี่ยวชาญ"
4. เอา interests ไปทำ dropdown "เลือกความสนใจ"
5. user เลือกค่า
6. กดค้นหา
7. เรียก GET /api/profile-search?expertise_group=<value>&interest=<value>
8. เอา response ไป render รายชื่อ

ตัวอย่าง fetch:

const params = new URLSearchParams({
  expertise_group: selectedExpertise || 'all',
  interest: selectedInterest || 'all',
  limit: '20',
});

const res = await fetch(`${API_URL}/api/profile-search?${params.toString()}`, {
  headers: {
    Authorization: `Bearer ${token}`,
    Accept: 'application/json',
  },
});

const users = await res.json();

============================================================
Endpoint แยก ถ้าต้องการโหลดเฉพาะ dropdown เดียว
============================================================

โหลดเฉพาะ dropdown "ค้นหาจาก":

GET /api/ref/search-fields

โหลดเฉพาะ dropdown "กลุ่มความเชี่ยวชาญ":

GET /api/ref/expertise-options

โหลดเฉพาะ dropdown "ความสนใจ":

GET /api/ref/interest-options

============================================================
สรุป endpoint สำคัญ
============================================================

GET /api/ref/search-fields
ใช้โหลด dropdown "ค้นหาจาก"

GET /api/ref/search-options
ใช้โหลด dropdown "ค้นหาจาก", "กลุ่มความเชี่ยวชาญ", "ความสนใจ" ในครั้งเดียว

GET /api/ref/expertise-options
ใช้โหลดเฉพาะ dropdown "กลุ่มความเชี่ยวชาญ"

GET /api/ref/interest-options
ใช้โหลดเฉพาะ dropdown "ความสนใจ"

GET /api/profile-search
ใช้ค้นหารายชื่อ โดยส่ง query params ตามรูปแบบที่ใช้

============================================================
หมายเหตุสำหรับ frontend
============================================================

GET request ไม่มี body
ให้ส่งค่าผ่าน query params เท่านั้น

ถ้าค่ามีช่องว่างหรือภาษาไทย ให้ใช้ URLSearchParams เพื่อ encode ให้ถูกต้อง

ตัวอย่าง:

const params = new URLSearchParams({
  search_from: 'interest',
  keyword: 'Machine Learning',
});

fetch(`${API_URL}/api/profile-search?${params.toString()}`, ...)
