1. AUTHENTICATION ENDPOINTS
================================================================================

POST /auth/login
  Description: Login ด้วย email และ password
  Auth: ไม่ต้อง
  Rate Limit: 5 requests per minute
  Request Body:
    {
      "email": "string|email|required",
      "password": "string|required"
    }
  Response (201):
    {
      "token": "string",
      "user": {
        "id": "integer",
        "code": "string",
        "full_name_th": "string",
        "full_name_en": "string",
        "email": "string",
        "faculty_name_th": "string",
        "department_name_th": "string",
        "picture": "string|nullable"
      }
    }

POST /auth/logout
  Description: Logout (ลบ token ปัจจุบัน)
  Auth: ต้อง
  Response (200):
    {
      "message": "Logged out successfully"
    }

6. RESOURCE ENDPOINTS (CRUD - Create, Read, Update, Delete)
================================================================================

Base Pattern: /api/{resource}
Supports: researches, journals, books, patents, awards, academics, trainings,
          lecturers, proceedings, hsps, workexes, boardexes, educations,
          interests, expertises

GET /{resource}
  Description: ดึงข้อมูลของ user ที่ login (Paginated)
  Auth: ต้อง
  Query Params (optional):
    per_page: "integer|min:1|max:100" (default: 20)
  Response (200):
    {
      "data": [...],
      "links": { ... pagination links ... },
      "meta": { ... pagination meta ... }
    }

POST /{resource}
  Description: เพิ่มข้อมูลใหม่
  Auth: ต้อง
  Request Body: ขึ้นอยู่กับ resource type (ดูตามด้านล่าง)
  Response (201): Created resource object

GET /{resource}/{id}
  Description: ดึงรายละเอียดข้อมูลเดียว
  Auth: ต้อง
  Response (200): Resource object

PUT /{resource}/{id}
  Description: อัปเดตข้อมูล
  Auth: ต้อง
  Request Body: Field ที่ต้องการอัปเดต
  Response (200): Updated resource object

DELETE /{resource}/{id}
  Description: ลบข้อมูล
  Auth: ต้อง
  Response (200):
    {
      "message": "ลบสำเร็จ"
    }

================================================================================
NOTES
================================================================================

1. ทุก timestamp อยู่ใน format: "Y-m-d H:i:s" (e.g., "2026-06-15 10:30:00")
2. Date อยู่ใน format: "Y-m-d" (e.g., "2026-06-15")
3. Pagination default: 20 items per page, max 100
4. ทั้ง sub_unit และ sub_unit_id ใช้ได้ (mapping เดียวกัน)
5. citizen_id, passport_id read-only (จาก SSO)
6. CORS enabled สำหรับทุก origin (dev mode)
7. Sanctum token format: "token_value|hash"
